## 8. Open-source Tools

**[table-to-sheets](https://github.com/skmalikllc/table-to-sheets)** ·
![tests](https://github.com/skmalikllc/table-to-sheets/actions/workflows/tests.yml/badge.svg)
Chrome MV3 extension. Pulls any HTML table off a page as CSV or straight into
Google Sheets — expanding `rowspan`/`colspan` first, so merged cells stop
shifting rows out of line. 7 unit tests, running in CI on Node 22 and 24.

**[contact-dedupe-mcp](https://github.com/skmalikllc/contact-dedupe-mcp)** ·
![tests](https://github.com/skmalikllc/contact-dedupe-mcp/actions/workflows/tests.yml/badge.svg)
MCP server. Profiles a contact export, finds the rows that are the same person
with the evidence for each match, merges them, and reports every conflicting
value instead of dropping one. 9 unit tests plus an end-to-end run over the real
protocol, on Node 20, 22 and 24.
